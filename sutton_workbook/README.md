# Sutton 强化学习练习册

这套练习册从 Sutton & Barto《Reinforcement Learning: An Introduction》里抽取高频、基础扎实、适合纸笔训练的习题，按主题拆成多张练习单。

原则：

- 只保留核心知识点
- 以中文改写原题，不大段搬运原文
- 优先选择适合独立推导、手算和短证明的题
- 以 `Chapter 2` 到 `Chapter 6` 为主

推荐顺序：

1. `01_bandits.md`
2. `02_mdp_and_bellman.md`
3. `03_dynamic_programming.md`
4. `04_monte_carlo.md`
5. `05_td_and_control.md`
6. `06_multistep_bootstrapping.md`
7. `07_planning_tabular.md`
8. `08_prediction_with_approximation.md`
9. `09_control_with_approximation.md`
10. `10_offpolicy_with_approximation.md`
11. `11_eligibility_traces.md`
12. `12_policy_gradient.md`

建议用法：

1. 每次只做一张练习单
2. 先合上书独立完成
3. 卡住时只回看定义和本章例子，不直接看答案
4. 做完后自己补一页“错因总结”
